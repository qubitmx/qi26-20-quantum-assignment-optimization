# QI26-20 preprint source

Compile from this directory with:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The repository-ready PDF is named `QI26_20_preprint.pdf`.

The paper is based on the executed repository artifact, the archived IBM Quantum job `d9vl8qfo3ppc73akfak0`, and the figures embedded in the executed notebook. The `Data/` directory contains the complete decoded hardware distributions and derived metric audit.
